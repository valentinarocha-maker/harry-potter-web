⚡ Harry Potter - Sitio Web Oficial

> Un sitio web educativo y profesional dedicado a la saga cinematográfica de Harry Potter, desarrollado como proyecto académico para la materia de **Diseño Web - Segundo Parcial.



  Descripción del Proyecto

Este es un sitio web completamente funcional y responsivo que presenta información detallada, completa y bien estructurada sobre la saga de Harry Potter. El proyecto incluye 8 páginas HTML semánticas con contenido multimedia, formularios funcionales y diseño profesional.

Información que puedes encontrar:

- Sobre la Saga: Sinopsis completa, análisis de impacto cultural, locaciones de filmación y reproductor de audio
-  Reparto: Galería de actores principales con biografías detalladas
-  Producción: Cronología de filmación en tabla profesional, efectos especiales y banda sonora
-  Curiosidades: Datos fascinantes del rodaje, cifras de producción y tabla de premios
-  Contacto: Formulario funcional con validaciones y enlaces a redes sociales
-  Confirmación: Página de confirmación de envío del formulario
-  Error 404: Página personalizada para URLs no encontradas

 Páginas Incluidas

1. Inicio (index.html)
Página principal con presentación de la saga, imagen destacada y datos rápidos.

2. Sobre la Saga (sobre-la-saga.html)
- Sinopsis completa
- Análisis de impacto cultural y social
- Locaciones de filmación con enlaces a Google Maps
- Reproductor de audio con controles
- Datos de producción

3. Reparto (reparto.html)
- Protagonistas (Daniel Radcliffe, Emma Watson, Rupert Grint)
- Profesores (Alan Rickman, Maggie Smith, Richard Harris)
- Antagonistas (Ralph Fiennes, Helena Bonham Carter, Tom Felton)
- Imágenes y biografías detalladas
- Grid responsivo de actores

4. Producción (produccion.html)
- Tabla profesional de cronología de filmación
- Efectos especiales y tecnología
- Compositores de la banda sonora
- Datos sobre los Estudios Leavesden
- Información sobre Warner Bros. Pictures

5. Curiosidades (curiosidades.html)
- Anécdotas memorables del rodaje
- Números impresionantes de producción
- Impacto cultural y comunidad de fanáticos
- Tabla de premios y galardones
- Nominaciones al Oscar
- Récords financieros

6. Contacto (contacto.html)
- Formulario funcional con validaciones
- Enlaces a redes sociales con íconos
- Plataformas de streaming
- Recursos oficiales
- Información de contacto

7. Confirmación (confirmacion.html)
- Página de éxito después del envío del formulario
- Enlaces de navegación rápida
- Mensaje amigable

8. Error 404 (404.html)
- Página personalizada para URLs no encontradas
- Diseño consistente con el sitio
- Botones de navegación

Validaciones del Formulario

El formulario de contacto incluye validaciones:

- Nombre: Requerido, 3-50 caracteres  
- Apellido: Requerido, 3-50 caracteres  
- Email: Requerido, validación de formato  
- Tema: Selección obligatoria (5 opciones)  
- Mensaje: Requerido, 10-500 caracteres  
- Redireccionamiento: Lleva a confirmacion.html
